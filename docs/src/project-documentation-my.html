MVP ဝဘ်အက်ပ် — ရှင်းလင်းချက်နှင့် နည်းပညာ
ပရောဂျက် အသေးစိတ်
ပရောဂျက် အမည်ReLoop (ယာယီအမည် — နောက်ဆုံးအမည်ကို အတည်ပြုရန်)
အခြေခံသည့် စာတမ်းHackathon ပရောဂျက် အဆိုပြုလွှာ — “ပတ်ဝန်းကျင် ရေရှည်တည်တံ့ရေးနှင့် ဘေးအန္တရာယ် ခံနိုင်ရည်ရှိရေးအတွက် နည်းပညာ”
ပရောဂျက် အမျိုးအစားဝဘ်အခြေပြု ပတ်ဝန်းကျင် ရေရှည်တည်တံ့ရေး ပလက်ဖောင်း
ရည်ရွယ်သည့် နေရာမြန်မာနိုင်ငံ
ပရောဂျက် အဆင့်MVP — နမူနာ ဒေတာဖြင့် အလုပ်လုပ်သော ဝဘ်အက်ပ်
ဘာသာစကားအင်္ဂလိပ်နှင့် မြန်မာ
စာတမ်း ရက်စွဲ၂၀၂၆ နိုဝင်ဘာ ၁၉
မလိုချင်သော ပစ္စည်းများကို အသုံးဝင်သော အရင်းအမြစ်များအဖြစ် ပြောင်းလဲခြင်း။

၁။ ဤစာတမ်းအကြောင်း

ဤစာတမ်းသည် hackathon အဆိုပြုလွှာမှ တည်ဆောက်ထားသော ReLoop ဝဘ်အက်ပ်နှင့် ၎င်းအသုံးပြုသည့် နည်းပညာကို ရှင်းပြသည်။ ပလက်ဖောင်းက ယနေ့ ဘာလုပ်နိုင်သည်ကို နားလည်လိုသော ဒိုင်လူကြီးများ၊ အဖွဲ့ဝင်များနှင့် မိတ်ဖက်များအတွက် ရေးသားထားသည်။

ကိုးကားသည့် စာတမ်း — Hackathon ပရောဂျက် အဆိုပြုလွှာ — ပတ်ဝန်းကျင် ရေရှည်တည်တံ့ရေးနှင့် ဘေးအန္တရာယ် ခံနိုင်ရည်ရှိရေးအတွက် နည်းပညာ (ဖိုင် — source/environmental_sustainability_hackathon_proposal.pdf)။ ဤစာတမ်းရှိ “အဆိုပြုလွှာ §၃.၁” ကဲ့သို့သော အပိုင်းနံပါတ်များသည် ထိုအဆိုပြုလွှာကို ရည်ညွှန်းသည်။ အဆိုပြုလွှာက ပလက်ဖောင်း ဘာကြောင့် လိုအပ်သည်ကို ရှင်းပြပြီး ဤစာတမ်းက ဘာတည်ဆောက်ပြီးပြီ နှင့် ဘယ်လို အလုပ်လုပ်သည် ကို ရှင်းပြသည်။

နယ်ပယ် — ထုတ်ကုန် ရှင်းလင်းချက်၊ လုပ်ဆောင်ချက်များ၊ စာမျက်နှာများနှင့် နည်းပညာ။ ဒေတာ သိမ်းဆည်းမှု ဒီဇိုင်းကို ဤစာတမ်းတွင် မဖော်ပြပါ။

၂။ ပရောဂျက် အကျဉ်းချုပ်

ReLoop သည် မြန်မာနိုင်ငံတွင် အမှိုက်ညစ်ညမ်းမှုကို လျှော့ချပြီး စွန့်ပစ်ပစ္စည်းများကို ပြန်လည်အသုံးပြုခြင်းနှင့် ပြန်လည်အသုံးချခြင်းကို အားပေးသော ဝဘ်အခြေပြု ပလက်ဖောင်း ဖြစ်သည် (အဆိုပြုလွှာ §၁)။ မလိုချင်သော ပစ္စည်းများ အသုံးပြုနိုင်သူများထံ ရောက်ရှိစေရန် တစ်ဦးချင်း၊ ပစ္စည်းဟောင်းဆိုင်များ၊ အဖွဲ့အစည်းများနှင့် လုပ်ငန်းများကို ချိတ်ဆက်ပေးသည်။

အဆိုပြုလွှာ §၂ ပါ ပြဿနာ သုံးခုကို ချိတ်ဆက်ထားသော အစိတ်အပိုင်း သုံးခုဖြင့် ဖြေရှင်းသည် (အဆိုပြုလွှာ §၃) —

ပြဿနာ (အဆိုပြုလွှာ §၂)အစိတ်အပိုင်းအက်ပ်က ဖြေရှင်းပုံ
အမှိုက်ထုတ်သူနှင့် ပြန်လည်အသုံးချသူကြား ချိတ်ဆက်မှု မရှိခြင်းစွန့်ပစ်ပစ္စည်း ဈေးကွက်အဖွဲ့ဝင်များက ပစ္စည်းကို ရောင်းရန်၊ အခမဲ့ သို့မဟုတ် လိုချင်ကြောင်း တင်သည်။ အခြားသူများက တောင်းဆိုပြီး လက်ခံမှသာ ဆက်သွယ်ရန် အချက်အလက် ဖလှယ်သည်။
အမှိုက်ရှိရာ နေရာများအကြောင်း သတင်းအချက်အလက် နည်းခြင်းအမှိုက်မြေပုံမည်သူမဆို စွန့်ပစ်အမှိုက်ကို မြေပုံပေါ်တွင် pin ချနိုင်ပြီး admin များက တိုင်ကြားချက်တစ်ခုစီကို ဖြေရှင်းပြီးအထိ အဆင့်လိုက် ရွှေ့သည်။
ပြန်လည်အသုံးပြုမှုအပေါ် အသိပညာ နည်းခြင်းပြန်သုံးနည်းများပစ္စည်းအလိုက် အဆင့်လိုက် လမ်းညွှန်များ၊ ခက်ခဲမှုနှင့် ဘေးကင်းရေး မှတ်ချက်များ၊ ကိုက်ညီသော ကြော်ငြာများသို့ link။

အသုံးပြုသူများ (အဆိုပြုလွှာ §၄)

အသုံးပြုသူအက်ပ်တွင် လုပ်နိုင်သည်များ
တစ်ဦးချင်းပစ္စည်း ရောင်း၊ ပေးကမ်း သို့မဟုတ် တောင်းဆို၊ အမှိုက်ပုံ တိုင်ကြားပြီး ကြည့်ရှု။
ပစ္စည်းဟောင်းဆိုင်သံအပိုင်းအစ လိုချင်ကြောင်း တင်၊ ပြန်လည်အသုံးချနိုင်သော ပစ္စည်းများ အများအပြား ဝယ်၊ ခွဲခြားထားသော ပစ္စည်း ရောင်း။
အဖွဲ့အစည်းပရောဂျက်များအတွက် ပစ္စည်း စုဆောင်း၊ သန့်ရှင်းရေး လုပ်၊ အမှိုက်ပုံ တိုင်ကြား။
လုပ်ငန်းပြန်လည်အသုံးချရေး သို့မဟုတ် ထုတ်လုပ်ရေးအတွက် ကုန်ကြမ်း ရှာ၊ ထုတ်လုပ်မှု အပိုအကျန် ရောင်း။
Adminတိုင်ကြားချက် အတည်ပြု၊ ကြော်ငြာ စစ်ဆေး၊ အဖွဲ့ဝင်၊ အမျိုးအစားနှင့် နည်းလမ်းများ စီမံ။

၃။ ပြီးစီးသော လုပ်ဆောင်ချက်များ

၃.၁ စွန့်ပစ်ပစ္စည်း ဈေးကွက် (အဆိုပြုလွှာ §၃.၁)

အဖွဲ့ဝင်များသည် ကြော်ငြာများကို card များဖြင့် ကြည့်ပြီး စကားလုံးဖြင့် ရှာ၊ ကြော်ငြာ အမျိုးအစား၊ ပစ္စည်း အမျိုးအစား၊ မြို့နှင့် အခြေအနေအလိုက် စစ်ထုတ်၊ အသစ်ဆုံး၊ ဈေးနှုန်း သို့မဟုတ် ပမာဏအလိုက် စီနိုင်သည်။ ကြော်ငြာတစ်ခုစီတွင် ပစ္စည်း၊ ပမာဏနှင့် ယူနစ်၊ ဈေးနှုန်း (ရှိလျှင်)၊ တည်နေရာ (မြို့၊ မြို့နယ်နှင့် မြေပုံ pin) နှင့် အခြေအနေ ပါဝင်သည်။

ကြော်ငြာ အမျိုးအစားအက်ပ်တွင် အဓိပ္ပာယ်
ရောင်းရန်ပိုင်ရှင်က တစ်ယူနစ်ဈေး (ကျပ်) ဖြင့် ရောင်းသည်။ ဈေးနှုန်း မဖြစ်မနေ လိုအပ်သည်။
အခမဲ့ပိုင်ရှင်က ပစ္စည်းကို အခမဲ့ ပေးကမ်းသည်။ ဈေးနှုန်း မသိမ်းပါ။
လိုချင်သည်ပိုင်ရှင်က ပစ္စည်း ရှာဖွေနေသည်။ အခြားအဖွဲ့ဝင်များက ကမ်းလှမ်းသည်။

ပိုင်ရှင်များသည် ကြော်ငြာကို ဖွင့်ထား၊ ခေတ္တရပ်၊ ကြိုတင်ယူထား၊ ပြီးဆုံး သို့မဟုတ် ပိတ် အဖြစ် အချိန်မရွေး ပြောင်းနိုင်သည်။

၃.၂ တောင်းဆိုခြင်း၊ ဖလှယ်ခြင်းနှင့် ဆက်သွယ်ရေး လုံခြုံမှု (အဆိုပြုလွှာ §၃.၁)

  1. အဖွဲ့ဝင်တစ်ဦးက ကြော်ငြာ တင်သည်။
  2. အခြားအဖွဲ့ဝင်က ကြော်ငြာကို ဖွင့်ပြီး ပမာဏနှင့် စာတိုဖြင့် တောင်းဆိုချက် ပို့သည်။ “လိုချင်သည်” ကြော်ငြာတွင် ၎င်းသည် ကမ်းလှမ်းချက် ဖြစ်သည်။
  3. ကြော်ငြာပိုင်ရှင်က လက်ခံ သို့မဟုတ် ငြင်းပယ်သည်။ ပိုင်ရှင်သာ လုပ်နိုင်ပြီး ကိုယ့်ကြော်ငြာကို ကိုယ်တိုင် တောင်းဆို၍ မရပါ။
  4. လက်ခံပြီးနောက် နှစ်ဖက်စလုံး Telegram၊ ဖုန်း သို့မဟုတ် အီးမေးလ်ကို မြင်ရပြီး ဖလှယ်မှုကို ကိုယ်တိုင် စီစဉ်သည်။
  5. ပိုင်ရှင်က ဖလှယ်မှု ပြီးဆုံးကြောင်း မှတ်သည်။ တောင်းဆိုသူက စောင့်ဆိုင်းဆဲ သို့မဟုတ် လက်ခံပြီး တောင်းဆိုချက်ကို ပယ်ဖျက်နိုင်သည်။
ဆက်သွယ်ရေး လုံခြုံမှု — ဆက်သွယ်ရန် အချက်အလက်များကို ကြော်ငြာ သို့မဟုတ် အများမြင် ပရိုဖိုင်တွင် ဘယ်တော့မှ မပြပါ။ တောင်းဆိုချက် လက်ခံပြီး သို့မဟုတ် ပြီးဆုံးပြီးမှသာ ကြော်ငြာပိုင်ရှင်နှင့် တောင်းဆိုသူ နှစ်ဦးကြားသာ ပြသည်။ အဆိုပြုလွှာတွင် ဖော်ပြထားသည့်အတိုင်း MVP သည် ငွေပေးချေမှုနှင့် ပို့ဆောင်ရေးကို မဆောင်ရွက်ပါ။

၃.၃ အမှိုက်မြေပုံ (အဆိုပြုလွှာ §၃.၂)

တိုင်ကြားချက်များကို OpenStreetMap မြေပုံပေါ်တွင် အရောင်ခွဲ pin များဖြင့် ပြပြီး ဘေးရှိ စာရင်းကို ရှာဖွေခြင်း၊ အခြေအနေနှင့် အမှိုက်အမျိုးအစားအလိုက် စစ်ထုတ်ခြင်း ပြုလုပ်နိုင်သည်။ pin ကို နှိပ်လျှင် အမျိုးအစား၊ ဖော်ပြချက်၊ ခန့်မှန်း ပမာဏ၊ တည်နေရာ၊ တိုင်ကြားသူနှင့် တိုးတက်မှု အဆင့်များကို ပြသည်။ မြေပုံကို နှိပ်ခြင်း သို့မဟုတ် စက်၏ တည်နေရာကို သုံးခြင်းဖြင့် တိုင်ကြားချက် အသစ် ပြုလုပ်နိုင်သည်။

အခြေအနေမြေပုံ အရောင်အဓိပ္ပာယ်
တိုင်ကြားပြီးအနီရပ်ရွာအဖွဲ့ဝင်က တိုင်ကြားထားပြီး အတည်ပြုရန် စောင့်ဆိုင်းနေသည်။
အတည်ပြုပြီးလိမ္မော်Admin က စစ်ဆေးပြီး သိမ်းဆည်းရန် စာရင်းသွင်းထားသည်။
သိမ်းဆည်းပြီးအပြာအမှိုက်ကို သိမ်းဆည်းပြီးဖြစ်သည်။
ဖြေရှင်းပြီးအစိမ်းနေရာ သန့်ရှင်းသွားပြီး ကိစ္စ ပိတ်လိုက်ပြီ။

အဆိုပြုလွှာအတိုင်း အမှိုက်တိုင်ကြားချက်သည် ဈေးကွက် ကြော်ငြာနှင့် သီးခြားဖြစ်သည် — နေရာတစ်ခုကို တိုင်ကြားခြင်းဖြင့် ပစ္စည်းကို ရောင်းရန် တင်ခြင်း မဟုတ်ပါ။

၃.၄ ပြန်သုံးနည်းနှင့် ပြန်လည်အသုံးချနည်းများ (အဆိုပြုလွှာ §၃.၃)

နည်းလမ်းများကို admin များက ပြင်ဆင်ထားခြင်း ဖြစ်ပြီး (AI ဖြင့် မထုတ်ပါ) ပစ္စည်းနှင့် နည်းစနစ် (ပြန်လည်အသုံးပြု / ပြန်လည်အသုံးချ) အလိုက် စစ်ထုတ်နိုင်သည်။ နည်းလမ်းတစ်ခုစီတွင် ဖော်ပြချက်၊ အဆင့်လိုက် လုပ်ဆောင်ပုံ၊ ခက်ခဲမှု၊ ဘေးကင်းရေး မှတ်ချက်နှင့် ကိုက်ညီသော ကြော်ငြာများ ပါဝင်သည်။ Demo တွင် အဆိုပြုလွှာပါ ဥပမာအားလုံးကို လွှမ်းခြုံသော နည်းလမ်း ၁၄ ခု ပါဝင်သည် —

ပစ္စည်းအက်ပ်ရှိ နည်းလမ်းများ
ပလတ်စတစ် ပုလင်းပန်းအိုး၊ eco-brick၊ ခွဲခြားထားသော PET ရောင်းခြင်း
ကတ်ထူမြေဆွေးမြေဩဇာ ပစ္စည်း၊ သေတ္တာထုတ်လုပ်သူထံ ရောင်းခြင်း
ဖန်ပုလင်းအလှဆင်ခြင်း၊ ပြန်သုံးနိုင်သော သိုလှောင်ဘူး
တာယာဟောင်းဥယျာဉ် ပန်းအိုး
သံအပိုင်းအစအလူမီနီယမ် သံဘူးများကို ပစ္စည်းဟောင်းဝယ်သူထံ ရောင်းခြင်း
အဝတ်ဟောင်းသန့်ရှင်းရေး အဝတ်စ၊ ကော်ဇော
အခြားအီလက်ထရောနစ် အမှိုက် ဘေးကင်းစွာ အပ်နှံခြင်း၊ ဝရန်တာတွင် မြေဆွေး ပြုလုပ်ခြင်း၊ pallet ခုံ

၃.၅ ပံ့ပိုးသော လုပ်ဆောင်ချက်များ (အဆိုပြုလွှာ §၆)

  • စာရင်းသွင်းခြင်းနှင့် ဝင်ရောက်ခြင်း — အကောင့်အမျိုးအစားနှင့် လျှို့ဝှက် ဆက်သွယ်ရန် အချက်အလက်ဖြင့် စာရင်းသွင်း၊ အီးမေးလ်ဖြင့် ဝင်ရောက်။
  • ပရိုဖိုင် — ကိုယ်ရေးအကျဉ်း၊ တည်နေရာ၊ ကြော်ငြာ၊ တိုင်ကြားချက်နှင့် လှုပ်ရှားမှု အရေအတွက်ပါ အများမြင် ပရိုဖိုင်။
  • ဒက်ရှ်ဘုတ် — ကျွန်ုပ်၏ ကြော်ငြာ၊ ဝင်လာ/ပို့ထားသော တောင်းဆိုချက်နှင့် ကျွန်ုပ်၏ တိုင်ကြားချက်များ တစ်နေရာတည်းတွင်။
  • Admin စီမံခန့်ခွဲမှု — တိုင်ကြားချက် အခြေအနေ ပြင်၊ ကြော်ငြာ အခြေအနေ စစ်ဆေး၊ အဖွဲ့ဝင် ပိတ်/ပြန်ဖွင့်၊ အမျိုးအစား ဖွင့်/ပိတ်၊ နည်းလမ်း ထုတ်ဝေ/ဖျောက်။
  • ပင်မစာမျက်နှာနှင့် အကြောင်း စာမျက်နှာ — ပလက်ဖောင်း စာရင်းအင်း၊ နောက်ဆုံး ကြော်ငြာနှင့် တိုင်ကြားချက်များ၊ ပရောဂျက်၏ ရည်ရွယ်ချက်နှင့် မျှော်မှန်းချက်။
  • တုံ့ပြန်မှုရှိသော ဒီဇိုင်း — ဖုန်း၊ တက်ဘလက်နှင့် ကွန်ပျူတာတွင် အလုပ်လုပ်ပြီး အလင်း/အမှောင် theme ပါသည်။
  • အင်္ဂလိပ်နှင့် မြန်မာ — header မှ ဘာသာစကား ပြောင်းနိုင်ပြီး ရက်စွဲနှင့် မြန်မာ ဂဏန်းများ အပါအဝင် interface တစ်ခုလုံး ပြောင်းသည်။

ဤဇယားသည် အဆိုပြုလွှာ၏ MVP နယ်ပယ်ပါ အချက်တိုင်းကို ဤ build ရှိ အခြေအနေနှင့် ချိတ်ဆက်ပြသည်။

လုပ်ဆောင်ချက် (အဆိုပြုလွှာ §၈)အခြေအနေမှတ်ချက်
Authentication နှင့် ပရိုဖိုင်Demoစာရင်းသွင်း၊ ဝင်ရောက်ခြင်းနှင့် ပရိုဖိုင် အလုပ်လုပ်သည်။ စကားဝှက်ကို မစစ်ဆေးသေးပါ။ Role များ စမ်းရန် demo အသုံးပြုသူ ပြောင်းစနစ် ပါသည်။
ပစ္စည်း အမျိုးအစားများပြီးပြီအမျိုးအစား ၁၀ ခု — admin က ဖွင့်/ပိတ်နိုင်သည်။
ဈေးကွက် ကြော်ငြာများပြီးပြီတင်၊ ကြည့်၊ ရှာ၊ စစ်ထုတ်၊ စီ၊ အခြေအနေ ပြောင်း။
ပစ္စည်း တောင်းဆိုချက်များပြီးပြီပို့၊ လက်ခံ၊ ငြင်းပယ်၊ ပယ်ဖျက်၊ ပြီးဆုံးကြောင်း မှတ်။
လက်ခံပြီးမှ ဆက်သွယ်ရန် မျှဝေခြင်းပြီးပြီစာမျက်နှာနှင့် action တိုင်းတွင် server ဘက်မှ စစ်ဆေးသည်။
အမှိုက် တိုင်ကြားခြင်းပြီးပြီမြေပုံ pin၊ အမျိုးအစား၊ အသေးစိတ်၊ ခန့်မှန်း ပမာဏ။ ဓာတ်ပုံ တင်ခြင်းမှာ နောက်အဆင့်။
အပြန်အလှန် အမှိုက်မြေပုံပြီးပြီအရောင်ခွဲ pin၊ popup၊ အခြေအနေနှင့် အမျိုးအစား စစ်ထုတ်ခြင်း၊ ရှာဖွေခြင်း။
တိုင်ကြားသူ အချက်အလက်ပြီးပြီတိုင်ကြားချက်တိုင်းတွင် ပြပြီး တိုင်ကြားသူ ပရိုဖိုင်သို့ link ပါသည်။
ပြန်သုံးနည်း အကြံပြုချက်များပြီးပြီနည်းလမ်း ၁၄ ခု — admin က ထုတ်ဝေ/ဖျောက်နိုင်သည်။
Admin စီမံခန့်ခွဲမှုပြီးပြီတိုင်ကြားချက်၊ ကြော်ငြာ၊ အဖွဲ့ဝင်၊ အမျိုးအစားနှင့် နည်းလမ်းများ။
အသိပေးချက်များမပါဝင်အဆိုပြုလွှာအတိုင်း MVP နယ်ပယ် ပြင်ပ။
အွန်လိုင်း ငွေပေးချေမှုမပါဝင်အဆိုပြုလွှာအတိုင်း MVP နယ်ပယ် ပြင်ပ။
AI အကြံပြုချက်များအနာဂတ်အဆိုပြုလွှာအတိုင်း အနာဂတ် ဖွံ့ဖြိုးမှု။
စိန်ခေါ်မှုနှင့် အဆင့်ဇယားအနာဂတ်အဆိုပြုလွှာအတိုင်း အနာဂတ် ဖွံ့ဖြိုးမှု။
အင်္ဂလိပ်နှင့် မြန်မာ interfaceထပ်တိုးအဆိုပြုလွှာထက် ပိုသည် — မြန်မာ အသုံးပြုသူများအတွက် ဘာသာစကား နှစ်မျိုး။

၇။ ပရောဂျက်ကို run ရန်

လိုအပ်ချက် — Node.js 20 နှင့်အထက်၊ npm။ ပရောဂျက် ဖိုင်တွဲမှ —

cd web
npm install
npm run dev        # ပြီးလျှင် http://localhost:3000 ကို ဖွင့်ပါ

Demo တွင် စကားဝှက် မလိုပါ။ ညာဘက်အပေါ်ရှိ အကောင့် မီနူးမှ demo အသုံးပြုသူများကို ပြောင်းနိုင်သည်၊ သို့မဟုတ် ဝင်ရောက်ရန် စာမျက်နှာတွင် demo အီးမေးလ်ဖြင့် ဝင်နိုင်သည်။ Header ရှိ ဘာသာစကား ခလုတ်ဖြင့် English နှင့် မြန်မာ ပြောင်းနိုင်သည်။

Demo အသုံးပြုသူRoleစမ်းကြည့်ရန် သင့်တော်သည်များ
Aung Min Thuတစ်ဦးချင်းဝင်လာသော တောင်းဆိုချက်များ လက်ခံခြင်း၊ လက်ခံပြီးနောက် ဆက်သွယ်ရန် မြင်ခြင်း
Shwe Pyi Junk Shopပစ္စည်းဟောင်းဆိုင်လိုချင်သည် ကြော်ငြာ၊ စောင့်ဆိုင်းဆဲနှင့် လက်ခံပြီး တောင်းဆိုချက်
Green Yangon Initiativeအဖွဲ့အစည်းအမှိုက် တိုင်ကြားချက်များနှင့် eco-brick ကြော်ငြာ
Platform AdminAdminAdmin စီမံခန့်ခွဲမှု — တိုင်ကြားချက် အခြေအနေ၊ အဖွဲ့ဝင်၊ အမျိုးအစား၊ နည်းလမ်း

Demo တွင် ပြုလုပ်သော ပြောင်းလဲမှုများ (ကြော်ငြာ၊ တောင်းဆိုချက်၊ တိုင်ကြားချက်၊ အကောင့် အသစ်များ) သည် server ပြန်မစမချင်း ရှိနေမည်။

၈။ နောက်အဆင့်များ

  1. နမူနာ ဒေတာအစား စီစဉ်ထားသော PostgreSQL database ကို Prisma ဖြင့် ချိတ်ဆက်ရန် (အဆိုပြုလွှာ §၉)။ စာမျက်နှာများကို ပြောင်းရန် မလိုပါ။
  2. Demo ဝင်ရောက်ခြင်းကို လုံခြုံသော session သို့မဟုတ် JWT authentication နှင့် စကားဝှက် စစ်ဆေးမှုဖြင့် အစားထိုးရန်။
  3. Cloudinary သို့မဟုတ် Supabase Storage ဖြင့် ကြော်ငြာနှင့် တိုင်ကြားချက်များအတွက် ဓာတ်ပုံ တင်ခြင်း ထည့်ရန်။
  4. Vercel သို့ deploy လုပ်ပြီး ရန်ကုန်နှင့် မန္တလေးရှိ ပစ္စည်းဟောင်းဆိုင်များ၊ ရပ်ရွာအဖွဲ့များနှင့် စမ်းသပ်ရန်။
  5. စတင်မိတ်ဆက်မီ မြန်မာ စကားလုံးများကို မိခင်ဘာသာ စကားပြောသူများဖြင့် ပြန်လည်စစ်ဆေးရန်။

၉။ နိဂုံး

MVP သည် အဆိုပြုလွှာပါ အစိတ်အပိုင်း သုံးခု — လုံခြုံသော ဆက်သွယ်ရေး ဖလှယ်မှုပါ စွန့်ပစ်ပစ္စည်း ဈေးကွက်၊ ရပ်ရွာ အမှိုက်မြေပုံနှင့် ပြန်သုံးနည်းများ — ကို ပရိုဖိုင်၊ ဒက်ရှ်ဘုတ်၊ admin စီမံခန့်ခွဲမှုနှင့် ဘာသာစကား နှစ်မျိုး interface တို့နှင့်အတူ ပေးဆောင်သည်။ မြန်မာနိုင်ငံ၏ ပတ်ဝန်းကျင် အမှိုက်ပြဿနာများကို ပလက်ဖောင်းက မည်သို့ ဖြေရှင်းသည်ကို သရုပ်ပြရန် အသင့်ဖြစ်ပါပြီ။

အမှိုက်သည် ပစ္စည်းတစ်ခု၏ အဆုံးသတ်ချည်း မဟုတ်ရပါ။
၎င်းသည် အခြားအရင်းအမြစ်တစ်ခု၏ အစ ဖြစ်နိုင်သည်။

ကိုးကားချက် — Hackathon ပရောဂျက် အဆိုပြုလွှာ၊ ပတ်ဝန်းကျင် ရေရှည်တည်တံ့ရေးနှင့် ဘေးအန္တရာယ် ခံနိုင်ရည်ရှိရေးအတွက် နည်းပညာ — စွန့်ပစ်ပစ္စည်း ဖလှယ်ရေးနှင့် ပတ်ဝန်းကျင် မြေပုံ ပလက်ဖောင်း (environmental_sustainability_hackathon_proposal.pdf)၊ အပိုင်း ၁–၁၁။
